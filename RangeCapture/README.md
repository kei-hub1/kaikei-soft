# RangeCapture

画面上の指定した範囲だけをキャプチャし、その場に最前面で表示しておく Windows 用ソフトです。

- 実行ファイル: `bin/RangeCapture.exe`（単体で動作。インストール・ランタイム不要）
- 動作環境: Windows 10 / 11（64bit）

## 使い方

1. `RangeCapture.exe` を起動すると、すぐにキャプチャモードになります（画面は暗くなりません。カーソルが十字になります）。
   - 初回起動時（保存先が未設定、または設定したフォルダが無くなっている場合）は、先に保存先フォルダの選択画面が出ます。
     キャンセルするとそのまま終了します。
2. 左ボタンでドラッグして範囲を選びます。選択中の範囲の外側に紫の枠線が付きます。
   - 押した点と離した点のピクセルを両方含む範囲になります（画面の右端・下端の 1 ピクセルまで選べます）。
   - ドラッグせずにクリックしただけの場合は確定せず、続けて選び直せます。
3. 左ボタンを離すとキャプチャされ、
   - 画像がキャプチャした位置と同じ場所に、常に最前面のウィンドウで表示されます。
     画面と見分けやすいよう、画像の外側に紫の枠線（拡大率 100% で 4 ピクセル、150% なら 6 ピクセル）と影が付きます。
     タイトルバーはありません。コピー・保存される画像には枠線も影も入りません。
   - 保存先フォルダに PNG で自動保存されます（ファイル名は日時。例: `20261120_153012_345.png`）。
4. キャプチャモード中に **Esc** または **右クリック** で、キャプチャせずに終了します。
5. 表示ウィンドウの右クリックメニュー「新しくキャプチャ」（または **N** キー）か、exe をもう一度起動すると、
   次のキャプチャができます。表示中のウィンドウはそのまま残るので、何枚でも並べておけます。

### 表示ウィンドウの操作

- 画像を **左ドラッグ** すると、好きな場所へ動かせます（別のモニターへも移せます。画像は等倍のまま）。
- 画像を **ダブルクリック** すると、そのウィンドウを閉じます（自動保存したファイルは残ります）。

右クリックメニュー:

| 項目 | キー | 内容 |
|---|---|---|
| 新しくキャプチャ | N | 次のキャプチャを始める（今の画像は残る） |
| コピー | Ctrl+C | 画像をクリップボードへコピー |
| 名前を付けて保存... | Ctrl+S | PNG / JPEG / BMP で保存（形式は拡張子で決まり、拡張子が無ければ「ファイルの種類」で決まります） |
| 保存先フォルダの変更... | | 自動保存先のフォルダを変更（次回以降のキャプチャから有効） |
| 閉じる | Esc | ウィンドウを閉じる |

### 古いスクショの自動削除

exe を起動するたびに、保存先フォルダ内の自動保存したスクショのうち、**撮ってから 7 日を過ぎたものをごみ箱へ移します**
（キャプチャの邪魔にならないよう裏で行います）。

- 対象は、保存先フォルダ直下にある日時名の PNG（`20261120_153012_345.png` の形）だけです。
  ほかの名前のファイル、JPEG / BMP、サブフォルダの中身には触りません。
- 撮った日時はファイル名で判断します。残したいものは名前を変えるか、別のフォルダへ移してください。
- ごみ箱が使えない場所（ネットワークドライブなど）が保存先の場合は、削除しません。
- exe を起動しない間は削除されません（常駐はしません）。

### タスクバーにピン留めする

1. `RangeCapture.exe` を、ずっと置いておくフォルダ（例: `C:\Tools\RangeCapture`）へ移します。
   ピン留めはファイルの場所を覚えるので、ダウンロードフォルダのままだと消したときに使えなくなります。
2. exe を右クリック →「タスクバーにピン留めする」を選びます
   （見当たらなければ「その他のオプションを確認」の中にあります）。
3. 以後はタスクバーのアイコンをクリックするだけでキャプチャを始められます。
   新しい版に入れ替えるときは、同じ場所・同じ名前で上書きすればピン留めはそのまま使えます。

### 設定ファイル

保存先フォルダは `%APPDATA%\RangeCapture\settings.ini` に保存されます。
削除すると、次回起動時に再びフォルダ選択画面が出ます。

### 拡大縮小・複数モニター

Per-Monitor DPI Aware (V2) として動作し、座標をすべて物理ピクセルで扱います。
画面の拡大縮小（125%、150% など）や、拡大率の異なる複数モニターでも、
選択範囲・キャプチャ画像・表示位置はずれません。
キャプチャモードはすべてのモニターを覆い、モニターをまたぐ範囲も選択・表示できます。

## ビルド方法

C++17 / Win32 API で書かれています（`src/main.cpp` の 1 ファイル）。MinGW-w64 でビルドします。

### Linux（Ubuntu など）でクロスビルド

```bash
sudo apt install g++-mingw-w64-x86-64
```

```bash
./build.sh
```

### Windows（MSYS2）でビルド

MSYS2 をインストールし、**MSYS2 MINGW64** シェルで:

```bash
pacman -S --needed mingw-w64-x86_64-gcc
```

```bash
./build.sh
```

どちらも `bin/RangeCapture.exe` が作られます（静的リンクのため、exe 単体で動作します）。

## ファイル構成

| パス | 内容 |
|---|---|
| `src/main.cpp` | ソースコード |
| `src/app.manifest` | DPI 対応（PerMonitorV2）などの宣言 |
| `src/app.rc` | マニフェスト・アイコン・バージョン情報のリソース |
| `src/app.ico` | アプリのアイコン（`tools/make_icon.py` で作成。Pillow と numpy が必要） |
| `build.sh` | ビルドスクリプト |
| `bin/RangeCapture.exe` | ビルド済みの実行ファイル |
