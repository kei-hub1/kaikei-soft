# 財務エントリ (kaikei-soft)

会計事務所職員が 1 人で使うことを想定した、TKC「財務エントリ 21」ライクな仕訳入力・帳票ソフトです。
ブラウザで動くローカルアプリで、データはパソコン内の SQLite ファイル 1 つ (`data/kaikei.db`) に保存されます。
インターネット接続やアカウント登録は不要です。

## 主な機能

| 区分 | 機能 |
| --- | --- |
| 顧問先管理 | 複数顧問先 (法人 / 個人)、会計期間 (期首・期末・締切)、消費税の経理方式 (税込 / 税抜 / 免税) |
| マスタ | 勘定科目表 (コード・名称とも自由に設定可能、一覧上で直接編集、CSV 取込・出力、他の顧問先からの複写)、補助科目・部門、定型仕訳 |
| 仕訳入力 | キーボード主体の高速入力、単一仕訳と振替伝票 (複合仕訳)、科目のコード・かな・名称検索、消費税区分と内税額の自動計算、差額自動入力、定型仕訳 (F2)、前伝票複写 (F5) |
| 帳票 | 仕訳帳、総勘定元帳 / 補助元帳、残高試算表 (期間指定・補助科目別)、月次推移表、消費税集計表、決算書 (貸借対照表 / 損益計算書)。各帳票は印刷と CSV 出力に対応 |
| 期末処理 | 期首残高入力、繰越処理 (翌期の自動作成と期首残高転記、当期純利益を繰越利益剰余金 / 元入金へ加算) |
| データ | 仕訳 CSV 出力 / 取込 (UTF-8 / Shift_JIS)、DB バックアップのダウンロード |

税抜経理の顧問先では、課税取引の仕訳を入力すると本体金額と仮払消費税 / 仮受消費税に自動分離して元帳・試算表に転記します。
仕訳データ自体は税込金額で保持するため、経理方式を後から変更しても再入力は不要です。

## 動作環境

- Python 3.10 以上 (Windows / macOS / Linux)
- モダンブラウザ (Edge / Chrome / Firefox)

## インストールと起動

```bash
git clone https://github.com/kei-hub1/kaikei-soft.git
cd kaikei-soft
pip install -r requirements.txt
python run.py
```

`python run.py` を実行すると `http://127.0.0.1:8765/` がブラウザで自動的に開きます。
Windows では同梱の `start.bat` をダブルクリックしても起動できます。終了はコンソールで `Ctrl+C` です。

オプション:

```
python run.py --port 9000        # ポート変更
python run.py --no-browser       # ブラウザを自動で開かない
KAIKEI_DB=D:\kaikei\office.db python run.py   # DB ファイルの場所を変更 (環境変数)
```

すでに起動している状態でもう一度実行した場合は、二重起動せずに既存の画面をブラウザで開きます。

## Windows で自動起動にする

`autostart-on.bat` をダブルクリックすると、次の設定が行われます。

- Windows にサインインしたときに、サーバーが最小化された状態で自動的に立ち上がります。
- デスクトップに「財務エントリ」のショートカット (`http://127.0.0.1:8765/`) を作成します。

以後は、デスクトップのショートカットをダブルクリックするだけで使えます。
自動起動をやめるときは `autostart-off.bat` をダブルクリックしてください。

内部では、スタートアップフォルダーに `ZaimuEntry-Server.lnk` を作成し、
`start-background.vbs` 経由で `start.bat --no-browser` を最小化起動しています。
管理者権限は不要で、変更はサインイン中のユーザーの範囲に限られます。
`start-background.vbs` が無い場合は `autostart-on.bat` が自動生成します。

### バッチファイルの文字コード (保守上の注意)

`*.bat` は **Shift_JIS (CP932) + CRLF** で保存すること。UTF-8 にすると、
cmd.exe が全角文字の途中で行を分断し、次のような誤動作が起きる。

```
'ドし直してください。' is not recognized as an internal or external command
```

同じ理由から、日本語のメッセージを `if ... ( ... )` のブロック内に置かない。
分岐はラベルと `goto` で書く。`.gitattributes` で `*.bat -text` を指定し、
Git が改行や文字コードを変換しないようにしている。

`start-background.vbs` は ASCII のみで記述する。`wscript` は `.vbs` を
システムのコードページで読むため、非 ASCII 文字は文字化けする。

## 最初の使い方

1. 「顧問先・会計期間」で顧問先を追加します。標準の勘定科目表と当期の会計期間が自動で作られます。
2. 必要に応じて「勘定科目」で補助科目 (取引先・銀行口座など) を追加します。
3. 前期からの残高がある場合は「期首残高」を入力します。
4. 「仕訳入力」で仕訳を入力します。
5. 「残高試算表」「総勘定元帳」などで確認し、必要に応じて印刷 / CSV 出力します。
6. 決算確定後、「データ管理」→「繰越処理」で翌期へ残高を繰り越します。

## 勘定科目表

顧問先の新規作成時に、次の 3 つから選べます。既定は TKC です。

| 科目表 | 内容 |
| --- | --- |
| TKC コード体系 | `docs/tkc_codes.md` の勘定科目コードに基づく 4 桁コード |
| 汎用 (3 桁コード) | 一般的な科目体系 |
| 空 | 科目を入れずに作成。CSV 取込や他の顧問先からの複写で用意する |

### TKC コード体系について

`docs/tkc_codes.md` に記載されたコードと科目名をそのまま収録しています。
同ファイルの方針どおり、**記載のないコードは推測で補っていません**。

そのため、次の科目だけは暫定コード `Z01` `Z02` `Z03` `Z04` で収録しており、
科目名の末尾に「※コード要確認」と付けています。実際の TKC コードが分かり次第、
「勘定科目」画面でコードと科目名を書き換えてください。書き換えても入力済みの
仕訳には影響しません。暫定コードが残っている間は、同画面の上部に注意書きが出ます。

| 暫定コード | 科目名 | 状況 |
| --- | --- | --- |
| Z01 | 仮受消費税等 | `docs/tkc_codes.md` で「未確認」。税抜経理の消費税転記に必要 |
| Z02 | 未払消費税等 | `docs/tkc_codes.md` で「未確認」 |
| Z03 | 繰越利益剰余金 | 資料に記載なし。法人の繰越処理に必要 |
| Z04 | 元入金 | 資料に記載なし。個人の繰越処理に必要 (個人のみ) |

次の科目は資料上「未確定」(資料間でコードが一致しない) のため、収録していません。
コードを確定のうえ、「勘定科目」画面で追加してください。

- 保険積立金 (候補 1253 または 1258)
- リース料 (候補 6234 または 6228)

法人には `3111 資本金` と `Z03 繰越利益剰余金` を、個人には `9411 事業主貸`
`9311 事業主借` `Z04 元入金` を入れています。
製造原価の労務費 (`5431`〜`5438`) は、本ソフトに製造原価報告書が無いため
売上原価の区分に置いています。

### 消費税の課税区分について

`docs/tkc_codes.md` の課税区分コードは、参照用として API (`/api/meta` の
`tkc_tax_divisions`) と各税区分の `tkc` 欄に対応表として保持しています。

ただし**本ソフトの消費税計算は TKC の課税区分そのものではありません**。
本ソフトは「税率 + インボイス経過措置の控除割合」で区分しており、
TKC の用途区分 (課税売上げにのみ要する / 非課税売上げにのみ要する / 共通) による
**個別対応方式の控除計算には未対応**です。課税売上割合が 95% 未満で個別対応方式を
使う顧問先では、消費税集計表の控除対象税額をそのまま申告に使わないでください。

## 勘定科目表を自分の体系に合わせる

勘定科目のコードと名称は、事務所で使っている体系にそのまま置き換えられます。
仕訳・期首残高・定型仕訳は科目コードではなく内部の科目 ID で結び付いているため、
**コードや名称を後から変更しても、過去に入力した仕訳は影響を受けません**。

「勘定科目」画面でできること:

| 操作 | 内容 |
| --- | --- |
| 直接編集 | 一覧のコード・科目名・かな・表示区分・既定の税区分・役割・並び順・有効をその場で書き換え、「変更を保存」でまとめて反映 |
| 行を追加 / 削除 | 科目の追加と削除。仕訳で使用中の科目は削除できないので、「有効」のチェックを外して使わなくする |
| 並び順を整理 | 表示区分とコード順に並び順を振り直す |
| CSV 取込 | 自前の科目表を一括登録。「追加・更新のみ」と「CSV の内容に置き換える」を選べる |
| CSV 出力 | 現在の科目表を書き出す。Excel で編集して取り込み直せる |
| 他の顧問先から複写 | 事務所共通の科目表を 1 件で整えて、他の顧問先へ複写する |

新規顧問先の追加時に「標準の勘定科目表を入れる」のチェックを外すと、科目が空の状態で作成されます。
自前の科目表を取り込む場合や、他の顧問先から複写する場合に使ってください。

### 科目 CSV の形式

```
コード, 科目名, かな, 表示区分, 既定の税区分, 役割, 並び順, 有効
1101, 現金, げんきん, 流動資産, 00, , 10, 1
4101, 売上高, うりあげだか, 売上高, 課税売上 10%, , 20, 1
```

- **コード** で既存の科目と照合します。一致すれば更新、無ければ追加します。
- **表示区分** は決算書のどこに並べるかを決めます。`流動資産` `固定資産` `繰延資産`
  `流動負債` `固定負債` `純資産` `売上高` `売上原価` `販売費及び一般管理費`
  `営業外収益` `営業外費用` `特別利益` `特別損失` `法人税等` `その他` のいずれか。
  資産・負債などの大分類はここから自動的に決まります。
- **既定の税区分** はコード (`11`)、正式名称 (`課税売上 10%`)、略称 (`課売10`) のいずれでも指定できます。
- **役割** は帳票や繰越処理で特別扱いする科目を指定します。コードや名称を変えても
  処理が壊れないよう、コードではなくこの役割で識別しています。空欄可。
  `仮払消費税` `仮受消費税` `繰越利益剰余金` `元入金` `事業主貸` `事業主借` `諸口`
- `#` で始まる行は読み飛ばされます。文字コードは UTF-8 / Shift_JIS のどちらでも構いません。

取込前に「内容を確認」を押すと、追加・更新・削除の件数と、必要な役割が欠けていないかを
確認できます。役割が欠けていると、税抜経理の消費税転記や繰越処理が正しく動きません。

記入例は「CSV 取込」画面の「記入例をダウンロード」から取得できます。

## 仕訳入力のキー操作

| キー | 動作 |
| --- | --- |
| `Enter` | 次の項目へ (科目欄では候補を確定) |
| `Shift+Enter` | 前の項目へ |
| 日付欄 | `0401` のように月日 4 桁で入力可。`↑` `↓` で 1 日ずつ前後 |
| 科目欄 | コード (`111`)、かな (`ふつう`)、名称 (`普通`) で検索し `↑` `↓` で選択 |
| 金額欄で空欄のまま `Enter` | 貸借差額を自動入力 (振替伝票の最終行に便利) |
| 摘要欄で `Enter` | 貸借一致なら登録、不一致なら行を追加 |
| `Ctrl+Enter` | 登録 |
| `Esc` | 入力をクリア |
| `Ctrl+Ins` / `Ctrl+Del` | 行追加 / 行削除 |
| `F2` | 定型仕訳を呼び出す |
| `F5` | 直前に登録した伝票を複写 |

## データのバックアップ

すべてのデータは `data/kaikei.db` に保存されます。「データ管理」→「バックアップをダウンロード」で
コピーを取得できます。復元するときは、アプリを停止した状態で `data/kaikei.db` をバックアップファイルで置き換えてください。

## CSV 形式 (仕訳)

ヘッダ行付き。同じ「日付 + 伝票番号」の行は 1 伝票にまとめられます。

```
日付, 伝票番号, 借方科目コード, 借方科目名, 借方補助コード, 借方補助名, 借方部門コード,
貸方科目コード, 貸方科目名, 貸方補助コード, 貸方補助名, 貸方部門コード,
金額, 消費税区分, 消費税額, 摘要, 伝票メモ
```

消費税区分コード: `00` 対象外 / `11` 課税売上10% / `12` 課税売上8%軽減 / `13` 非課税売上 / `14` 免税売上 /
`21` 課税仕入10% / `22` 課税仕入8%軽減 / `23` 非課税仕入 / `24` `25` 課税仕入(80%控除) / `26` `27` 課税仕入(50%控除) / `30` 不課税

## 開発

```bash
pip install -r requirements-dev.txt
python -m pytest tests          # API テスト
python run.py --reload          # ソース変更時に自動再起動
```

API ドキュメント: 起動後に `http://127.0.0.1:8765/api/docs`

### 構成

```
app/
  main.py          FastAPI アプリ
  db.py            SQLite スキーマ
  master_data.py   標準勘定科目表・消費税区分
  posting.py       仕訳→転記・帳票集計 (試算表 / 元帳 / 月次 / 消費税 / 決算書)
  routers/         API (顧問先・マスタ・仕訳・帳票・CSV)
static/            フロントエンド (依存ライブラリなしの HTML / CSS / JS)
tests/             pytest
```

## 制限事項・今後の課題

- 消費税額は仕訳ごとの内税計算 (切捨て) で、申告書の計算 (積上げ・割戻し) とは異なる場合があります。
- 減価償却・固定資産台帳、給与、電子申告連携などは対象外です。
- 同時に複数人で使うことは想定していません (ロック機構なし)。
