# 定型文書作成ツール

税理士事務所で使う定型文書（資料送付状・書類送付のお願い・顧客向けのお知らせなど）を、
画面入力だけで **Word（.docx）と PDF の両方** に出力するデスクトップアプリです。

- 宛先は顧客名簿から選ぶだけ。差出人（事務所情報）は一度登録すれば自動で入ります
- 文例（件名・本文）を選んで、その場で修正してから出力できます
- 「記書き」（記／書類一覧／以上）の有無を切り替えられます
- 文書の種類や文例は画面から自由に追加できるので、定型文書の種類を今後増やしていけます

---

## 1. セットアップ（初回のみ）

前提: Windows PC に **Python** と **Microsoft Word** がインストールされていること。

1. **zip を必ず解凍してから使います**（重要）
   - zip を開いたまま中の `.bat` をダブルクリックしても動きません
   - zip ファイルを右クリック →「すべて展開」→ できたフォルダを `C:\定型文書作成ツール` などに置きます
2. **`初回セットアップ.bat`** をダブルクリックします
   - 黒い画面が開き、必要なライブラリ（python-docx, pywin32）がインストールされます
   - 「セットアップが完了しました」と表示されたら、何かキーを押して閉じます
   - インターネットに接続した状態で実行してください

> Python が見つからないと表示された場合は、[python.org](https://www.python.org/downloads/windows/) から Python をインストールしてください。
> インストール時に **「Add python.exe to PATH」にチェック** を入れてください。
> Microsoft Store 版の Python では動かないことがあります。

## 2. 起動

**`起動.bat`** をダブルクリックします。黒い画面が一瞬出たあと、アプリの画面が開きます。

うまく開かないときは、**`診断.bat`** をダブルクリックしてください。
原因（Python が無い、ライブラリが入っていない、など）を調べて画面に表示し、
`logs\診断結果.txt` にも保存します。→ 詳しくは「6. うまくいかないとき」

初回起動時に、フォルダ内に次のものが自動で作られます。

| フォルダ／ファイル | 内容 |
|---|---|
| `data\app.db` | 顧客名簿・文例・設定などのデータ（1ファイル）。バックアップはこのファイルをコピーしてください |
| `logs\app.log` | 動作ログ・エラー内容 |
| `logs\起動エラー.txt` | 起動に失敗したときだけ作られます。原因が書かれています |
| `出力\` | 作成した Word・PDF の保存先（初期値。設定画面で変更できます） |

## 3. 最初にやること

1. **「設定（差出人・出力先）」タブ** で事務所の情報（税理士名・住所・電話番号など）を入力し、「差出人を保存」を押します
   - 事務所名は「吉川和章税理士事務所」が最初から入っています
   - 空欄の項目は文書に出力されません
2. **「顧客名簿」タブ** で宛先となる顧客を登録します

## 4. 各画面の使い方

### 4-1. 文書作成（メイン画面）

| 項目 | 説明 |
|---|---|
| 文書の種類 | 送付状／案内文 など。選ぶと、その種類の文例だけが「文例」に表示されます |
| 文例 | 選ぶと件名・本文・記書きの有無が右側に反映されます。反映後は自由に修正できます |
| 宛先 | 検索欄に名前の一部（会社名・氏名・部署名）を入れると絞り込まれます。一覧から選ぶと、文書に出力される宛先が下に表示されます |
| 作成日 | 初期値は当日。`2026/09/17` `令和8年9月17日` `R8.9.17` などの形式で入力できます。右に和暦が表示されます |
| 件名 | 中央に太字で出力されます |
| 本文 | 1行が1段落になります。「拝啓」「敬具」は自動で付くので入力不要です |
| 記書きあり | チェックすると「記」「書類一覧」「以上」が付きます。書類名と部数を入力し、「行を追加」「✕」で行を増減できます。部数に数字だけを入れると「1部」のように「部」が付きます（「一式」などはそのまま） |
| 作成 | Word と PDF を同時に出力し、完了後に出力フォルダを開きます |

- 宛先・件名・本文が未入力のときは作成せずにメッセージを表示します
- ファイル名は `作成日(YYYYMMDD)_宛先名_件名.docx` と同名の `.pdf` です。同名ファイルがあるときは `_2` `_3` … と連番を付け、上書きしません
- PDF 変換に失敗した場合でも Word ファイルは残り、失敗した理由を表示します

### 4-2. 顧客名簿

- 一覧から選ぶと右側で編集できます。「新規」で空のフォームになります
- 項目: 会社名、部署名、氏名、敬称（様／御中／殿／先生。直接入力も可）、郵便番号、住所1、住所2
- 会社名のみ・氏名のみでも登録できます。氏名がない場合は会社名に敬称が付きます（例: 「株式会社○○　御中」）
- 空欄の項目は文書に出力されません（余計な空行は残りません）

### 4-3. 文例管理

- 一覧から選んで編集、「新規」「複製」で追加、「削除」で削除します
- 項目
  - 文例名、文書の種類、件名、本文（「拝啓」「敬具」を除いた部分）
  - 記書きあり（初期値）: この文例を選んだときの記書きチェックの初期値
  - 頭語／結語: 初期値は「拝啓」「敬具」。不要な文書では空欄にできます
  - 書類一覧の初期値: 記書きに載せる書類の初期値。1行に1件、「書類名,部数」の形式（例: `決算報告書,1`）
- **文書の種類を増やす**: 「種類を管理…」ボタンから種類（例: 挨拶状、契約書送付状）を追加・名前変更・削除できます。文例で使用中の種類は削除できません

#### 差し込み記号

件名・本文に次の記号を書いておくと、作成時に自動で置き換わります（全角の｛ ｝でも可）。

| 記号 | 置き換わる内容 |
|---|---|
| `{宛名}` | 宛先の氏名＋敬称（氏名がなければ会社名＋敬称） |
| `{会社名}` | 宛先の会社名 |
| `{氏名}` | 宛先の氏名 |
| `{作成日}` | 作成日（和暦。例: 令和8年9月17日） |
| `{事務所名}` | 差出人の事務所名 |
| `{税理士名}` | 差出人の税理士名 |
| `{担当者名}` | 差出人の担当者名 |

記号を増やしたい場合は `app/placeholders.py` の `PLACEHOLDERS` に1行追加するだけで、画面の説明にも自動で反映されます。

#### 最初から登録されている文例

| 文例名 | 種類 | 記書き |
|---|---|---|
| 資料送付のご案内 | 送付状 | あり |
| 書類ご送付のお願い | 送付状 | あり |
| お知らせ | 案内文 | なし |

### 4-4. 設定（差出人・出力先）

- 差出人: 事務所名、税理士名、郵便番号、住所、電話番号、FAX番号、メールアドレス、担当者名
  - 税理士名は文書上で「税理士　○○」と表示されます
- 出力先フォルダ: 「参照…」で選んで「出力先を保存」。初期値はアプリフォルダ内の「出力」フォルダです

## 5. 出力される文書のレイアウト

A4縦・横書き、MS 明朝、本文 10.5pt、件名 12pt 太字、余白 25mm。上から順に:

1. 作成日（和暦・右寄せ）
2. 宛先（郵便番号、住所、会社名（部署名）、氏名＋敬称・左寄せ）
3. 差出人（右寄せ。登録した項目のみ）
4. 件名（中央・太字）
5. 「拝啓」＋本文（時候の挨拶なし）
6. 「敬具」（右寄せ）
7. 記書きありの場合: 「記」（中央）、書類一覧（番号・書類名・部数）、「以上」（右寄せ）

`samples\` フォルダに、記書きあり／なしのサンプル（Word・PDF）があります。

## 6. うまくいかないとき

### 起動.bat を押しても何も起きない

まず **`診断.bat`** をダブルクリックしてください。原因を調べて画面に表示し、最後にアプリを起動します
（このときはエラーが画面に残るので、内容を確認できます）。結果は `logs\診断結果.txt` にも保存されます。

よくある原因は次の4つです。

| 原因 | 見分け方 | 対処 |
|---|---|---|
| zip を解凍していない | 画面に `Temp\...zip...\診断.py: No such file or directory` のようなパスが出る。アドレス欄に zip 名が残っている | zip を右クリック →「すべて展開」してから、展開先のフォルダで実行する |
| Python が入っていない／PATH に無い | 診断で「Python が見つかりません」 | [python.org](https://www.python.org/downloads/windows/) からインストール。**「Add python.exe to PATH」にチェック**。Microsoft Store 版は不可 |
| tkinter が入っていない | 診断で「tkinter」が NG | Python を入れ直し、インストール画面で **「tcl/tk and IDLE」にチェック** |
| ライブラリ未インストール | 診断で「python-docx」が NG | `初回セットアップ.bat` を実行 |

起動に失敗した場合、理由は `logs\起動エラー.txt` にも書き出されます。

### その他

| 症状 | 対処 |
|---|---|
| PDF 変換に失敗する | Word がインストールされているか確認してください。Word ファイルは作成されているので、Word で開いて「名前を付けて保存」→ PDF でも作成できます |
| 「ファイルを保存できませんでした」と出る | 同じ名前のファイルを Word で開いたままになっていないか確認し、閉じてから再度「作成」を押してください |
| その他のエラー | `logs\app.log` にエラー内容が記録されます |

## 7. 開発者向け

```
main.py                  起動スクリプト
診断.py                  起動できないときの原因調査
起動.bat                 ダブルクリック起動（pythonw 使用）
初回セットアップ.bat     requirements.txt のインストール
診断.bat                 診断 → コンソール表示のままアプリ起動
requirements.txt
app/
  paths.py               各フォルダのパス
  logger.py              ログ設定
  models.py              データ構造（顧客・差出人・文例・作成依頼）
  db.py                  SQLite スキーマ・初期データ
  repositories.py        DB の読み書き
  wareki.py              和暦変換・日付解析
  placeholders.py        差し込み記号
  filenames.py           ファイル名の生成
  docx_builder.py        python-docx による Word 生成（レイアウト）
  pdf_converter.py       PDF 変換（Word COM → LibreOffice の順で試す）
  service.py             入力チェック → Word 保存 → PDF 変換
  ui/                    tkinter 画面（app.py, main_tab.py, customers_tab.py, templates_tab.py, settings_tab.py, widgets.py）
tests/                   自動テスト（python -m unittest discover -s tests）
samples/                 確認用サンプル出力
```

- テスト実行: `python -m unittest discover -s tests -v`
- Windows 以外（Word がない環境）では、LibreOffice がインストールされていれば PDF 変換にそれを使います
