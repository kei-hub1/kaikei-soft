# 財務エントリ 自動入力（会計伝票・月次入力）

通帳の CSV に入っている仕訳を、TKC「財務エントリ」の会計伝票画面へ自動で入力します。
関与先・CSV・月を画面で選び、ボタンを押すだけで使えます。

## 最初の準備（1回だけ）

1. ブラウザで https://github.com/kei-hub1/kaikei-soft/tree/claude/sleepy-heisenberg-zcx9hn を開きます。緑色の「**Code**」ボタンを押し、「**Download ZIP**」を押します。
2. ダウンロードした ZIP ファイルを右クリックし、「**すべて展開**」を押します。展開したフォルダーは、分かりやすい場所に置きます（例：`C:\財務エントリ自動入力`）。
3. フォルダーの中の「**準備.bat**」をダブルクリックします。
   - 必要なライブラリが入り、デスクトップに「**財務エントリ自動入力**」のショートカットができます。
   - 「Windows によって PC が保護されました」と表示されたら、「詳細情報」を押し、「実行」を押します。

## ふだんの使い方

デスクトップの「**財務エントリ自動入力**」をダブルクリックすると、次の画面が開きます。

```
関与先 [10614 望月昭光        ▼] [関与先を追加] [フォルダーを開く]
消費税 ◉課税（税区分の欄から入力）  ○免税（借方科目の欄から入力）
CSV    [通帳.csv              ▼] [最新の状態にする]
月     ┌──────────┬────┬──────────┐
       │ 2026年1月 │ 32 │ 入力済み   │
       │ 2026年2月 │ 28 │ 未入力     │
       └──────────┴────┴──────────┘
[確認] [メモ帳で練習] [入力開始] [中止]          [この月の記録を消す]
```

### はじめての関与先のとき

1. 「**関与先を追加**」を押し、関与先コードと関与先名を入れます。
2. 「**課税**」か「**免税**」を選びます。選んだ内容は関与先ごとに保存され、次からは自動で選ばれます。
3. 「**フォルダーを開く**」を押し、開いたフォルダーに通帳の CSV を入れます。
4. 「**最新の状態にする**」を押します。

### 入力するとき

1. 関与先、CSV、月を選びます。
2. 「**確認**」を押し、入力される内容に誤りがないかを見ます（キーは送りません）。
3. 財務エントリで、その関与先の「会計伝票」（月次入力）を、その月にして開きます。
4. 「**入力開始**」を押し、表示された内容を確かめて「はい」を押します。
5. 財務エントリの画面をクリックし、カーソルを新しい行の「**税区分**」の欄に置きます（免税の関与先は「**借方科目**」の欄）。
6. **PgUp** を押すと、入力が始まります。

| 入力中の操作 | キー・ボタン |
|---|---|
| 一時停止 | **PgDn** |
| 再開 | **PgUp** |
| やめる | 自動入力の画面の「**中止**」ボタン |

- 財務エントリ以外のウィンドウが前に出ると、自動で一時停止します。
- 途中でやめても、どこまで入力したかを覚えています。次に「入力開始」を押すと、続きから入力します。
  - 1件の途中でやめた場合は、財務エントリに入力途中の行が残ります。手で消してから続けてください。
- その月を最初から入力し直すときは、「**この月の記録を消す**」を押します。
- 練習するときは、メモ帳を開いてから「**メモ帳で練習**」を押します（記録は本番とは別に残ります）。

### 入力されないもの（CSV に誤りがあるとき）

次のいずれかに当てはまる仕訳があると、その月は1件も入力せずに知らせます。

- 借方科目が 9411・1113 以外、または貸方科目が 9311・1113 以外のとき
- 摘要が全角15文字を超えるとき
- 日付や金額を読み取れないとき

## フォルダーの中身

```
財務エントリ自動入力\
  準備.bat              … 最初の1回だけ使う
  起動.bat              … デスクトップのショートカットから呼ばれる
  config.toml           … キー操作の順番などの設定
  関与先\
    10614_望月昭光\
      通帳.csv          … 通帳の CSV（何か月分でも可）
      設定.toml         … 課税／免税（画面から書き換わる）
      記録\             … どこまで入力したか・入力ログ
    00000_練習用サンプル\  … 練習用のサンプル
```

新しい版に入れ替えるときは、「関与先」フォルダーはそのままにして、ほかのファイルだけを上書きしてください。

## CSV の形式

- 1行目は見出しです。文字コードは UTF-8 と Shift_JIS のどちらでも読めます。
- 列は見出しの名前で読み取るため、順番は問いません。
- 実際に使う列は、日付・借方科目コード・貸方科目コード・金額・取引先名・摘要の6つです。

```
日付,伝票番号,借方科目コード,借方科目名,借方補助コード,借方補助名,借方部門コード,貸方科目コード,貸方科目名,貸方補助コード,貸方補助名,貸方部門コード,金額,消費税区分,消費税額,取引先名,摘要,伝票メモ
```

## うまくいかないとき

- **キーが財務エントリに届かない**：財務エントリを管理者として実行している場合、このツールも管理者として実行しないとキーが届きません。
- **画面が開かない**：フォルダーに「エラー.txt」ができていれば、その中身を知らせてください。
- **キー操作の順番を変えたい**：`config.toml` の `[[steps]]` を書き換えます。書き方はファイルの中に説明があります。
