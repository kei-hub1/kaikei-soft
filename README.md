# 財務エントリ (kaikei-soft)

会計事務所職員が 1 人で使うことを想定した、TKC「財務エントリ 21」ライクな仕訳入力・帳票ソフトです。
ブラウザで動くローカルアプリで、データはパソコン内の SQLite ファイル 1 つ (`data/kaikei.db`) に保存されます。
インターネット接続やアカウント登録は不要です。

## 主な機能

| 区分 | 機能 |
| --- | --- |
| 顧問先管理 | 複数顧問先 (法人 / 個人)、会計期間 (期首・期末・締切) |
| 画面 | ライト / ダーク表示の切り替え (ヘッダー右のボタン。「自動」は Windows の設定に合わせる) |
| マスタ | 勘定科目表 (コード・名称とも自由に設定可能、一覧上で直接編集、CSV 取込・出力、他の顧問先からの複写)、補助科目・部門、摘要プリセット、定型仕訳 (複合仕訳も登録可) |
| 仕訳入力 | キーボード主体の高速入力、単一仕訳と振替伝票 (複合仕訳)、科目のコード・かな・名称検索、摘要のプリセット呼び出し、差額自動入力、資金諸口の貸借一致チェック、定型仕訳の呼び出し (F2) と登録 (F3)、前伝票複写 (F5) |
| 帳票 | 仕訳帳、総勘定元帳 / 補助元帳、残高試算表 (期間指定・補助科目別)、月次推移表、摘要別集計、決算書 (貸借対照表 / 損益計算書)。各帳票は印刷と CSV 出力に対応。**仕訳帳・総勘定元帳は行をクリックしてその場で修正・削除できる** |
| 期末処理 | 期首残高入力、繰越処理 (翌期の自動作成と期首残高転記、当期純利益を繰越利益剰余金 / 元入金へ加算) |
| データ | 仕訳 CSV 出力 / 取込 (UTF-8 / Shift_JIS、日付・金額・摘要が同じ伝票は飛ばす)、DB バックアップのダウンロード |

**消費税は扱いません。** 消費税の申告が必要な顧問先 (課税事業者・インボイス登録事業者など) は別のソフトで処理する前提です。
金額は入力したまま (税込) で帳簿に載ります。仕訳入力に税区分・消費税額の欄は無く、消費税集計表もありません。

以前の版で入力した消費税区分・消費税額は、データベースに残したまま使っていません (消してはいません)。
以前に「税抜経理」にしていた顧問先があった場合、その顧問先の試算表・決算書は、
仮払・仮受消費税に分けない税込の金額で表示されるようになります。

## 動作環境

- Python 3.10 以上 (Windows / macOS / Linux)
- モダンブラウザ (Edge / Chrome / Firefox)

## インストールと起動

```bash
git clone https://github.com/kei-hub1/kaikei-soft.git
cd kaikei-soft
pip install -r requirements.txt
python run.py
```

`python run.py` を実行すると `http://127.0.0.1:8765/` がブラウザで自動的に開きます。
Windows では同梱の `start.bat` をダブルクリックしても起動できます。終了はコンソールで `Ctrl+C` です。

オプション:

```
python run.py --port 9000        # ポート変更
python run.py --no-browser       # ブラウザを自動で開かない
KAIKEI_DB=D:\kaikei\office.db python run.py   # DB ファイルの場所を変更 (環境変数)
```

すでに起動している状態でもう一度実行した場合は、二重起動せずに既存の画面をブラウザで開きます。

## 最新版に更新する

`update.bat` をダブルクリックすると、最新版をダウンロードしてプログラムを入れ替えます。
`data` フォルダー (入力済みのデータ) には触れず、更新前に自動でバックアップを取ります。

**`update.bat` は一度置けば、それ以降ずっと使い回せます。** 毎回もらい直す必要はありません。
このファイル自体が新しくなったときも、更新のついでに自動で入れ替わります
(実行中は自分を書き換えられないため、`update-new.bat` として受け取り、画面を閉じた数秒後に差し替えます)。

起動中は更新できません。先にアプリを終了 (黒いウィンドウを閉じる) してから実行してください。

手作業で更新する場合は、次の ZIP をダウンロードして展開し、`data` フォルダー以外を
上書きコピーしてください。

```
https://github.com/kei-hub1/kaikei-soft/archive/refs/heads/claude/financial-entry-21-clone-o7te5r.zip
```

**既にある顧問先の勘定科目表は自動では変わりません。** 更新後に科目体系を切り替えるには、
「勘定科目」画面の「科目表を入れ替える」を使ってください。

## Windows で自動起動にする

`autostart-on.bat` をダブルクリックするか、「データ管理」画面の **PC 起動時の自動起動** で
「自動起動を有効にする」を押すと、次の設定が行われます (管理者権限は不要)。

- Windows にサインインしたときに、財務エントリが**窓を出さずに**自動で立ち上がります。
  「ブラウザで画面も開く」にしておくと、画面もそのまま開きます。
- デスクトップに「財務エントリ」のショートカット (`http://127.0.0.1:8765/`) を作ります (`autostart-on.bat` のみ)。

黒い窓が無いので、**終了するときは「データ管理」画面の「財務エントリを終了」**を使います。
`update.bat` は動いている財務エントリを自動で止めて更新し、終わったら起動し直します。
自動起動をやめるときは `autostart-off.bat` か、「データ管理」画面の「自動起動をやめる」を使います。

「データ管理」画面には、設定の状態 (有効 / 未設定 / 要対応) が出ます。次の場合は「要対応」になるので、
「設定し直す」を押してください。

- Windows の「スタートアップ アプリ」(タスク マネージャー) で無効にされている
- ソフトのフォルダーを移動した、Python を入れ直した
- 以前の方式で設定されている

起動時のメッセージやエラーは `data/logs/server.log` に残ります。立ち上がらないときはここを確認します。

### 仕組み (保守用)

`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` に `ZaimuEntry` という名前で
`"<Python のフォルダー>\pythonw.exe" "<ソフトのフォルダー>\run.py" --background` を登録します
(画面を開かない設定では末尾に `--no-browser`)。処理は `app/autostart.py` にあります。

以前は、スタートアップフォルダーの `ZaimuEntry-Server.lnk` から `start-background.vbs` (VBScript) 経由で
`start.bat` を最小化起動していました。この方式は、VBScript が無効になっている新しい Windows 11 や、
インターネットから入手したファイルへの警告で止まると、立ち上がりませんでした。
起動に失敗しても最小化された窓の中にしか表示されないため、原因も分かりませんでした。
**以前の方式が残っていると、財務エントリを起動したときに自動で今の方式へ切り替えます。**

`run.py` のオプション: `--background` (窓なしで動かす。出力はログへ) / `--start-background` (窓なしで別に起動してすぐ戻る) /
`--stop` (動いているものを止める) / `--autostart-on` / `--autostart-off` / `--autostart-status`。

### バッチファイルの文字コード (保守上の注意)

`*.bat` は **Shift_JIS (CP932) + CRLF** で保存すること。UTF-8 にすると、
cmd.exe が全角文字の途中で行を分断し、次のような誤動作が起きる。

```
'ドし直してください。' is not recognized as an internal or external command
```

同じ理由から、日本語のメッセージを `if ... ( ... )` のブロック内に置かない。
分岐はラベルと `goto` で書く。`.gitattributes` で `*.bat -text` を指定し、
Git が改行や文字コードを変換しないようにしている。

`start-background.vbs` は ASCII のみで記述する。`wscript` は `.vbs` を
システムのコードページで読むため、非 ASCII 文字は文字化けする。

## 最初の使い方

1. 「顧問先・会計期間」で顧問先を追加します。選んだ勘定科目表と当期の会計期間が自動で作られます。
2. 必要に応じて「勘定科目」で補助科目 (取引先・銀行口座など) を追加します。
3. よく使う摘要 (売上先・仕入先など) を「摘要」画面に登録しておくと、仕訳入力が速くなります。
4. 前期からの残高がある場合は「期首残高」を入力します。
5. 「仕訳入力」で仕訳を入力します。
6. 「残高試算表」「総勘定元帳」などで確認し、必要に応じて印刷 / CSV 出力します。
   **総勘定元帳・仕訳帳では、行をクリックするとその場で仕訳を修正できます** (「仕訳入力」画面に戻る必要はありません)。
   試算表で科目をクリックすると元帳が開き、<kbd>Esc</kbd> で試算表の同じ位置に戻れます。
7. 決算確定後、「データ管理」→「繰越処理」で翌期へ残高を繰り越します。

## 勘定科目表

顧問先の新規作成時に、次の 3 つから選べます。既定は TKC です。

| 科目表 | 内容 |
| --- | --- |
| TKC コード体系 | `docs/tkc_codes.md` の勘定科目コードに基づく 4 桁コード |
| 汎用 (3 桁コード) | 一般的な科目体系 |
| 空 | 科目を入れずに作成。CSV 取込や他の顧問先からの複写で用意する |

### TKC コード体系について

`docs/tkc_codes.md` に記載されたコードと科目名をそのまま収録しています。
同ファイルの方針どおり、**記載のないコードは推測で補っていません**。

そのため、次の科目だけは暫定コード `Z01` `Z02` `Z03` `Z04` で収録しており、
科目名の末尾に「※コード要確認」と付けています。実際の TKC コードが分かり次第、
「勘定科目」画面でコードと科目名を書き換えてください。書き換えても入力済みの
仕訳には影響しません。暫定コードが残っている間は、同画面の上部に注意書きが出ます。

| 暫定コード | 科目名 | 状況 |
| --- | --- | --- |
| Z01 | 仮受消費税等 | `docs/tkc_codes.md` で「未確認」 |
| Z02 | 未払消費税等 | `docs/tkc_codes.md` で「未確認」 |
| Z03 | 繰越利益剰余金 | 資料に記載なし。法人の繰越処理に必要 |
| Z04 | 元入金 | 資料に記載なし。個人の繰越処理に必要 (個人のみ) |

次の科目は資料上「未確定」(資料間でコードが一致しない) のため、収録していません。
コードを確定のうえ、「勘定科目」画面で追加してください。

- 保険積立金 (候補 1253 または 1258)
- リース料 (候補 6234 または 6228)

法人には `3111 資本金` と `Z03 繰越利益剰余金` を、個人には `9411 事業主貸`
`9311 事業主借` `Z04 元入金` を入れています。
製造原価の労務費 (`5431`〜`5438`) は、本ソフトに製造原価報告書が無いため
売上原価の区分に置いています。

## 勘定科目表を自分の体系に合わせる

勘定科目のコードと名称は、事務所で使っている体系にそのまま置き換えられます。
仕訳・期首残高・定型仕訳は科目コードではなく内部の科目 ID で結び付いているため、
**コードや名称を後から変更しても、過去に入力した仕訳は影響を受けません**。

「勘定科目」画面でできること:

| 操作 | 内容 |
| --- | --- |
| 直接編集 | 一覧のコード・科目名・かな・表示区分・役割・並び順・有効をその場で書き換え、「変更を保存」でまとめて反映 |
| 科目表を入れ替える | 既にある顧問先に TKC / 汎用の科目表を後から適用する。コードが一致する科目は名称だけ更新され、仕訳は失われない |
| 行を追加 / 削除 | 科目の追加と削除。仕訳で使用中の科目は削除できないので、「有効」のチェックを外して使わなくする |
| 並び順を整理 | 表示区分とコード順に並び順を振り直す |
| CSV 取込 | 自前の科目表を一括登録。「追加・更新のみ」と「CSV の内容に置き換える」を選べる |
| CSV 出力 | 現在の科目表を書き出す。Excel で編集して取り込み直せる |
| 他の顧問先から複写 | 事務所共通の科目表を 1 件で整えて、他の顧問先へ複写する |

新規顧問先の追加時に「入れる勘定科目表」で「空」を選ぶと、科目が無い状態で作成されます。
自前の科目表を取り込む場合や、他の顧問先から複写する場合に使ってください。

### 科目 CSV の形式

```
コード, 科目名, かな, 表示区分, 役割, 並び順, 有効
1101, 現金, げんきん, 流動資産, , 10, 1
4101, 売上高, うりあげだか, 売上高, , 20, 1
```

- **コード** で既存の科目と照合します。一致すれば更新、無ければ追加します。
- **表示区分** は決算書のどこに並べるかを決めます。`流動資産` `固定資産` `繰延資産`
  `流動負債` `固定負債` `純資産` `売上高` `売上原価` `販売費及び一般管理費`
  `営業外収益` `営業外費用` `特別利益` `特別損失` `法人税等` `その他` のいずれか。
  資産・負債などの大分類はここから自動的に決まります。
- 以前の版で出力した CSV にある「既定の税区分」の列は読み飛ばします (そのまま取り込めます)。
- **役割** は帳票や繰越処理で特別扱いする科目を指定します。コードや名称を変えても
  処理が壊れないよう、コードではなくこの役割で識別しています。空欄可。
  `繰越利益剰余金` `元入金` `事業主貸` `事業主借` `諸口`
- `#` で始まる行は読み飛ばされます。文字コードは UTF-8 / Shift_JIS のどちらでも構いません。

取込前に「内容を確認」を押すと、追加・更新・削除の件数と、必要な役割が欠けていないかを
確認できます。役割が欠けていると、繰越処理が正しく動きません。

記入例は「CSV 取込」画面の「記入例をダウンロード」から取得できます。

## 摘要のプリセット

売上先・仕入先など、よく使う摘要は「摘要」画面に登録しておけます。
仕訳入力の摘要欄で候補が出るので、毎回打ち直す必要がありません。

| 操作 | 内容 |
| --- | --- |
| 呼び出し | 摘要欄で文字を打つと候補が絞り込まれます (変換前の読みでも出ます。下の「予測変換」)。`↑` `↓` で選んで `Enter` |
| コードで展開 | プリセットにコード (`1` など) を付けておくと、そのコード + `Enter` で本文に展開されます |
| 候補一覧 | 摘要欄で `F4` を押すと候補が一覧表示されます |
| 自由入力 | 候補に無い文字列はそのまま入力できます。プリセットへの登録は不要です |
| 関連科目 | プリセットに科目を紐付けておくと、その科目を使っている行では候補の上位に出ます |
| 過去から取り込む | 「摘要」画面の「過去の仕訳から取り込む」で、既に何度も使った摘要をまとめて登録できます |
| CSV 取込・出力 | 取引先一覧を Excel で作って一括登録できます。列は `コード, 摘要, かな, 関連科目コード, 並び順, 有効` |

プリセットを削除しても、入力済みの仕訳の摘要はそのまま残ります。

### 予測変換 (読みで候補を出す)

摘要欄では、**漢字に変換する前の読み (ひらがな) を打っている途中から候補が出ます。**
候補にはプリセットのほか、過去に入力・取り込んだ摘要がすべて含まれます (よく使うものほど上)。

```
摘要欄で「すいど」と打つ (変換前)  →  候補: 水道代
                                     確定 (Enter) してから ↓ Enter で選ぶ
```

- 通帳 CSV から取り込んだ**半角カナの摘要 (`ﾃﾞﾝｷ ﾀﾞｲ` など) は、ひらがなで打てばそのまま候補に出ます。**
  カタカナ・半角カナ・全角英数の違いや、空白は区別しません。
- 漢字の摘要は、**一度その読みで打って登録すると、読みを覚えます。** 次からは読みの途中で候補に出ます
  (例: 「すいどうだい」と打って「水道代」に変換して登録 → 次から「すいど」で出る)。
  読みは顧問先ごとに覚え、同じ摘要を別の読みで打てば新しい読みに置き換わります。
- 覚える前の漢字の摘要も、変換して漢字を確定すれば (「電気」など) 候補に出ます。
- プリセットの「かな」欄に読みを入れておけば、最初から読みで出ます。

## 摘要でまとめて見る

同じ摘要の取引をまとめて確認できます。取引先別の売上や仕入の把握に使えます。

### 複数行の仕訳 (複合仕訳)

1 回の取引で科目が 3 つ以上になるとき (給与の支払いなど) は、**行を足して 1 枚の伝票にまとめます。**

```
借方 給料手当 300,000                     摘要 1月分給与
                 貸方 預り金    30,000    摘要 源泉所得税
                 貸方 普通預金 270,000    摘要 振込
```

- **<kbd>Shift</kbd> を単独で押して離すと行が増えます** (「行追加」ボタン、<kbd>Ctrl+Ins</kbd> でも同じ)。
  <kbd>Shift+Enter</kbd> のように他のキーと組み合わせたときは増えません。
- **2 行目以降は、科目欄を空のまま <kbd>Enter</kbd> を押すと前の行と同じ科目が入ります。**
  資金諸口のように片側が同じ科目の行を続けて書くとき、打ち直さずに済みます。
  空のままにしたいときは <kbd>Enter</kbd> ではなく <kbd>Tab</kbd> で次の欄へ移ります。
- 貸借は**伝票全体で**一致していれば構いません。片側だけの行を並べられます。
- 金額欄を空のまま <kbd>Enter</kbd> を押すと、差額が入ります。
- まとめた行は同じ日付・同じ伝票番号になり、**修正・削除も伝票ごと**に行います。
- 総勘定元帳では、相手科目が 1 つに決まらないため **「諸口」** と表示されます。

### 資金諸口の貸借一致チェック (仕訳入力)

資金諸口を使った行があると、**フッターに資金諸口の借方合計・貸方合計・差額が出ます。**

```
借方 180,000  貸方 180,000  差額 0  |  資金諸口 借方 180,000 / 貸方 173,510 / 差額 6,490
```

- **差額が 0 になるまで登録できません。** 登録しようとすると
  「資金諸口の貸借が一致しません (借方 180,000 / 貸方 173,510 / 差額 6,490)」と知らせます。
- 摘要欄で <kbd>Enter</kbd> を押したときも、資金諸口が釣り合っていなければ
  登録せずに行を足します。1 行目を書いた時点で登録されてしまうことがありません。
- 対象になるのは、役割が「諸口」の科目 (TKC 科目表の `9991 資金諸口`) と、
  名称が「資金諸口」「諸口」の科目です。コードや名称を変えても追えるよう、役割を先に見ます。
- 資金諸口を使っていない仕訳では、この欄は出ません。

総勘定元帳・仕訳帳から開く修正ダイアログでも同じように働きます。

### 補助科目の選び方 (仕訳入力)

補助科目がある科目を入力して <kbd>Enter</kbd> を押すと、**補助科目の欄に移って候補が開きます。**
コードを覚えていなくても <kbd>↑</kbd><kbd>↓</kbd> と <kbd>Enter</kbd> で選べます。

```
1113 [Enter]  →  補助欄に移動し、候補が開く
                 01 A銀行 普通    ← 最初の候補が選ばれた状態
                 02 B信金 普通
              ↓ [Enter] で「02 B信金 普通」を確定 → 金額欄へ
```

- **何も打たずに <kbd>Enter</kbd> を押すと、コードが 1 (`1`・`01`・`001` など) の補助科目が入ります。**
  1 番の補助科目に、わざわざ「1」と打たなくて済みます。2 番以降は今までどおりコードを打つか、<kbd>↓</kbd> で選びます。
  コード 1 の補助科目が無い科目では、空のまま次へ進みます。
- 補助科目を空のままにしたい行は、<kbd>Enter</kbd> ではなく <kbd>Tab</kbd> で次の欄へ移ります。
- コード (`02`) やかな・名称を打って <kbd>Enter</kbd> でも選べます。
- 補助科目が登録されていない科目では候補は出ず、欄そのものを飛ばします。
- 既に補助科目が入っている行でも、その欄に入れば候補が開くので選び直せます
  (総勘定元帳から開く修正ダイアログでも同じです)。

### 科目はキーボードだけで開く

**仕訳帳・総勘定元帳・残高試算表は、開いた時点で科目の入力欄にカーソルが入っています。**
マウスに持ち替えず、コードを打って <kbd>Enter</kbd> を押すだけで科目が切り替わります。

| 画面 | コード + <kbd>Enter</kbd> の動き |
| --- | --- |
| 総勘定元帳 | その科目の元帳を表示 |
| 仕訳帳 | その科目の仕訳だけに絞り込み (空欄にして <kbd>Enter</kbd> で全科目に戻る) |
| 残高試算表 | その科目の総勘定元帳を開く (行のクリックと同じ) |

- コードのほか、**かな・科目名**でも探せます (「げんきん」「現金」いずれでも可)。
- 確定した後は入力欄の文字が選択状態のままなので、**続けて次のコードを打つだけ**で切り替わります。
- <kbd>↑</kbd><kbd>↓</kbd> で候補を選べます。該当が無いときは知らせるだけで、表示は変わりません。

残高試算表で科目を開き <kbd>Esc</kbd> で戻ると、またカーソルは入力欄にあります。
**「コード → <kbd>Enter</kbd> → 確認 → <kbd>Esc</kbd>」の繰り返しが、キーボードだけで回せます。**

### 帳票を掘り下げて、元の画面に戻る

- **残高試算表**で科目の行をクリックすると、その科目の**総勘定元帳**が開きます。
- **摘要別集計**で摘要の行をクリックすると、その摘要の仕訳だけを**仕訳帳**で開きます。

掘り下げた先で **<kbd>Esc</kbd> を押すと、元の画面に戻ります** (画面左上の「◀ 残高試算表へ戻る」でも同じです)。
戻ったときは、**見ていた期間・表示区分・チェックの状態・スクロール位置がそのまま復元され、
クリックした行が一瞬光ります。** 続けて別の科目を見ていく作業が、キーボードだけで進められます。

メニューから直接開いた総勘定元帳・仕訳帳には戻り先がないので、<kbd>Esc</kbd> を押しても何も起きません。
仕訳の修正ダイアログや科目の候補一覧が開いているときは、まずそちらが閉じます。

### 帳票から直接修正する

**総勘定元帳・仕訳帳で行をクリックすると、その仕訳を修正するダイアログが開きます。**
「仕訳入力」画面へ移動する必要はありません。

**まとめて直すとき**は、ダイアログの中で前後の仕訳へそのまま移れます。
仕訳帳で摘要を絞り込んでおけば、その並びを 1 件ずつ片付けられます。

- **保存すると、自動で次の仕訳に進みます** (最後まで行くと閉じます)。
- <kbd>PageDown</kbd> / <kbd>PageUp</kbd> または「次の仕訳 ▶」「◀ 前の仕訳」で前後に移れます。
  **直した内容があれば、移る前に保存します。** 直しかけのまま置き去りになりません。
- 貸借が合わないなど保存できない状態のときは移動せず、その場に留まってエラーを知らせます。
- 見出しに「3 / 12 件」と、いま何件目かが出ます。

- 仕訳入力と同じフォームなので、操作もキー割り当ても同じです (<kbd>Enter</kbd> で次の項目、
  科目はコード・かな・名称で検索、<kbd>F2</kbd> 定型仕訳、<kbd>F4</kbd> 摘要候補)。
- <kbd>Ctrl+Enter</kbd> または「修正を保存」で保存します。保存するとダイアログが閉じ、
  元帳・仕訳帳が新しい内容で引き直されます (残高も更新されます)。
- 「この伝票を削除」で削除もできます。
- <kbd>Esc</kbd> で閉じます。**直した内容があれば、閉じるときに保存します。**
  科目の候補一覧が開いているときは、まず候補だけが閉じます。
- 直した内容を捨てたいときは「変更を破棄して閉じる」を押します。

**仕訳帳で科目を変えると、摘要の絞り込みは自動で外れます。**
前の科目に合わせて入れた摘要が残っていると、新しい科目では 1 件も出ない、ということが起きるためです。

- **仕訳帳** と **総勘定元帳** の「並び順」で「摘要順」を選ぶと、同じ摘要がまとまり、摘要ごとの小計が入ります。
- **摘要別集計** は、摘要ごとの件数・借方・貸方・差引と、使われている科目・期間を一覧にします。
  行をクリックすると、その摘要の仕訳だけを仕訳帳で開きます。件数順・金額順にも並べ替えられます。

並び順は、プリセットに「かな」を登録していれば五十音順、無い場合は文字コード順です。
摘要が空の仕訳は最後にまとまります。

## 仕訳入力のキー操作

| キー | 動作 |
| --- | --- |
| `Enter` | 次の項目へ (科目欄では候補を確定) |
| `Shift+Enter` | 前の項目へ |
| 日付欄 | `0401` のように月日 4 桁で入力可。`↑` `↓` で 1 日ずつ前後 |
| 科目欄 | コード (`111`)、かな (`ふつう`)、名称 (`普通`) で検索し `↑` `↓` で選択 |
| 金額欄で空欄のまま `Enter` | 貸借差額を自動入力 (振替伝票の最終行に便利) |
| 摘要欄で `Enter` | 貸借一致なら登録、不一致なら行を追加 |
| `Ctrl+Enter` | 登録 |
| `Esc` | 入力をクリア |
| `Ctrl+Ins` / `Ctrl+Del` | 行追加 / 行削除 |
| `F2` | 定型仕訳を呼び出す |
| `F3` | いま入力されている伝票を、そのまま定型仕訳に登録 |
| `F5` | 直前に登録した伝票を複写 |
| `F4` | 摘要欄で候補の一覧を表示 |

### 画面に見えている内容がそのまま保存されます

科目や補助科目の欄は「打った文字」と「選んだ科目」を別に持っています。
**保存や別の伝票への移動をするときは、打った文字をその場で確定してから保存します。**
<kbd>Enter</kbd> を押し忘れても、画面に出ているとおりに保存されます。

見つからない科目を打ったまま保存しようとしたときは、保存も移動もせず
「2 行目: 借方科目「9999」が見つかりません」のように行と欄を示して知らせます。

### 修正中の内容は勝手に消えません

変更したかどうかは、**読み込んだ時点の内容と今の内容を突き合わせて**判定します。
文字を打った場合だけでなく、**定型仕訳の呼び出し・行の追加や削除・候補からの選択**も
変更として扱われるので、保存され損ねることがありません。
逆に、何も変えていない伝票を通り過ぎるときは保存しません。

- 伝票を修正している途中で別の伝票へ移ると、**移る前に保存します** (帳票の修正ダイアログ、
  「仕訳入力」画面の登録済み仕訳の一覧、どちらも同じです)。
- 保存できない状態のときは移動しません。
- 新規入力の途中で別の伝票を開こうとしたときは、入力内容が消えてよいか確認します。
- **修正ダイアログは、<kbd>Esc</kbd> や「閉じる」で閉じるときも保存します。**
  貸借が合わないなど保存できない状態のときは閉じず、その場でエラーを知らせます。
- 捨てたいときだけ「変更を破棄して閉じる」を押してください。

## 定型仕訳

毎月同じ形で起こす仕訳は「定型仕訳」に登録しておくと、<kbd>F2</kbd> で呼び出せます。
**複合仕訳 (伝票まるごと) を 1 つの定型にできます。**

```
給与支払                    ← 1 つの定型仕訳
  借方 給料手当 300,000       摘要 給与
       貸方 預り金   30,000    摘要 源泉所得税
       貸方 普通預金 270,000   摘要 振込
```

- 「定型仕訳」画面の「定型仕訳を追加」で、行を足しながら作れます。
  **「続けて登録する」にチェックを入れておくと、保存しても画面が閉じず、
  そのまま次の定型仕訳を登録できます。** コードは空いている番号が自動で入ります。
- 金額を空欄 (0) にしておくと、呼び出したときに都度入力します。
- 伝票メモも登録できます。呼び出したとき、伝票メモが空なら入ります。

### 入力済みの仕訳を定型にする

**仕訳入力画面で <kbd>F3</kbd> (または「定型登録」ボタン) を押すと、いま入力されている伝票が
そのまま定型仕訳になります。** 行・金額・摘要・伝票メモをすべて引き継ぎます。

過去に登録した伝票を定型にしたいときは、「登録済み仕訳」の一覧 (または総勘定元帳・仕訳帳) から
その伝票を開いてから <kbd>F3</kbd> を押してください。

## データのバックアップ

すべてのデータは `data/kaikei.db` に保存されます。「データ管理」→「バックアップをダウンロード」で
コピーを取得できます。復元するときは、アプリを停止した状態で `data/kaikei.db` をバックアップファイルで置き換えてください。

## CSV 形式 (仕訳)

ヘッダ行付き。同じ「日付 + 伝票番号」の行は 1 伝票にまとめられます。

### 通帳ごとに補助科目を付ける

通帳 (口座) ごとに CSV を分けて取り込む前提で、**ファイルを選ぶと「どの通帳の CSV ですか？」と必ず聞きます。**
選び忘れて補助科目なしで取り込んでしまうことがありません。

```
どの通帳の CSV ですか？        ファイル: JA本店.csv
  1113 普通預金
    ○ 01 JA 本店 普通
    ○ 02 ゆうちょ 通常
  ○ 補助科目を指定しない
  ▸ 新しい通帳 (補助科目) を登録する
```

- <kbd>↑</kbd><kbd>↓</kbd> で選んで <kbd>Enter</kbd>。ダブルクリックでも決まります。
- **登録されていない通帳は、その場で登録できます。** 科目は「普通預金」、コードは次の番号
  (01, 02 …) が自動で入るので、名称だけ打って <kbd>Enter</kbd> で登録・選択まで済みます。
  通帳が 1 冊も無い顧問先では、最初から登録欄が開きます。
- **ファイルを選び直すと、もう一度聞きます。** 前の通帳は引き継ぎません (別の通帳の CSV のため)。
- 「取込」を押したときの確認にも、「JA本店.csv を「1113 普通預金 / 01 JA 本店 普通」の
  通帳として取り込みます」と通帳名が出ます。
- 選び直したいときは「選び直す / 通帳を登録」を押します。
- 選んだ補助科目は、**その科目の行で補助科目が空のもの**に付きます。CSV に補助科目が書いてあればそちらを優先します。

### 科目表に無い科目が CSV にあるとき

検証・取込の前に、CSV の科目がこの顧問先の科目表にそろっているかを確かめます。
足りない科目があると一覧で示し、**確認のうえその場で追加して、そのまま取り込みに進めます。**
名称・表示区分・役割は TKC・汎用の科目表から候補が入ります (標準に無いコードは CSV の科目名を使います)。

よくある原因は**事業形態の登録違い**です。TKC 科目表の `9411 事業主貸`・`9311 事業主借` は
個人事業主の顧問先にだけ作られるため、**法人で登録した顧問先に事業主貸・事業主借の入った CSV を取り込むと、
科目が無いことになります。** 画面にもその旨が出ます。個人事業主であれば「顧問先・会計期間」で
事業形態を「個人」に直してください (直しても科目は自動では増えないので、取込の画面で追加してください)。

### CSV の日付を含む会計期間が無いとき

取込の前に、CSV の日付がすべて会計期間に入っているかも確かめます。入っていない日付があると、
**顧問先の事業形態・期首月に合わせた会計期間の直し方を示し、確認のうえその場で直して取り込みに進めます。**

- 個人事業主は 1月〜12月、法人は期首月から 1 年間の期間を作ります (例: 4 月始まりの法人に 3 月の通帳 → 前期を作成)。
- **法人で作った顧問先を個人に直した場合**、会計期間は法人の決算期 (例: 2026/04/01〜2027/03/31) のまま残っているため、
  1〜3 月の通帳が入りません。この場合は既存の期間を 2026/01/01〜2026/12/31 に直します。
  登録済みの仕訳が新しい期間からはみ出す場合や、締め切った期間は動かさず、すき間の期間だけを作ります。
- 締め切った会計期間に入る日付があるときは取り込みません。必要なら「顧問先・会計期間」で締切を解除してください。
- 顧問先の事業形態・期首月を直したとき、**まだ仕訳も期首残高も入れていなければ**、自動で作った会計期間も新しい決まりに合わせて直ります。

### 二重計上の防止

**日付・金額・摘要・補助科目が同じ伝票が既に登録されていれば、その行は取り込みません。**
巡回監査のたびに通帳履歴を CSV にして取り込んでも、前回取り込んだ分が重ねて計上されることはありません。

- 比較するのは **日付・金額・摘要・補助科目** です。科目・部門・伝票メモ・
  伝票番号は比較しません。通帳から取り込んだ仕訳は後で科目を付け替えるのが前提なので、
  付け替えた後に同じ期間を取り込み直しても重なりません。
- **補助科目 (通帳) だけは比較に含めます。** 別々の口座に同じ日・同じ金額・同じ摘要の入出金が
  あっても、片方が取り込まれないということが起きないようにするためです
  (例: A 銀行と B 信金の両方に「1/5 ATM入金 50,000」がある場合、両方とも取り込まれます)。
- 逆に、摘要を書き換えた伝票は一致しなくなります。摘要は通帳の記載のまま残し、
  補足は伝票メモに書くと安全です。
- 同じ日に同じ金額・同じ摘要の取引が本当に 2 回ある場合は、両方とも取り込みます。
  既に 1 件だけ登録されていれば、残りの 1 件を取り込みます。
- 飛ばした伝票は「検証」「取込」の結果に件数と一覧で表示されます。

```
日付, 伝票番号, 借方科目コード, 借方科目名, 借方補助コード, 借方補助名, 借方部門コード,
貸方科目コード, 貸方科目名, 貸方補助コード, 貸方補助名, 貸方部門コード,
金額, 摘要, 伝票メモ
```

以前の版で出力した CSV にある「消費税区分」「消費税額」の列は読み飛ばします (そのまま取り込めます)。

## 開発

```bash
pip install -r requirements-dev.txt
python -m pytest tests          # API テスト
python run.py --reload          # ソース変更時に自動再起動
```

API ドキュメント: 起動後に `http://127.0.0.1:8765/api/docs`

### 構成

```
app/
  main.py          FastAPI アプリ
  db.py            SQLite スキーマ
  master_data.py   標準勘定科目表
  posting.py       仕訳→転記・帳票集計 (試算表 / 元帳 / 月次 / 摘要別 / 決算書)
  routers/         API (顧問先・マスタ・仕訳・帳票・CSV)
static/            フロントエンド (依存ライブラリなしの HTML / CSS / JS)
tests/             pytest
```

## 制限事項・今後の課題

- 消費税は扱いません (申告が必要な顧問先は別のソフトで処理する前提)。
- 減価償却・固定資産台帳、給与、電子申告連携などは対象外です。
- 同時に複数人で使うことは想定していません (ロック機構なし)。
