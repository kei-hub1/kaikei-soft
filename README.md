# 財務エントリ 自動入力（会計伝票・月次入力）

CSV の仕訳を1行ずつ読み、TKC「財務エントリ」の会計伝票画面へキー操作を送って入力します。

- キー操作の順番は `config.toml` の `[[steps]]` で変えられます（コードの書き換えは不要です）
- 最前面のウィンドウが財務エントリでないときは、キーを送らずに止まります
- **PgDn** で一時停止し、**PgUp** で再開します
- どの行まで入力したかを記録し、次に実行したときは続きから入力します

## 準備（最初の1回）

```bash
py -m pip install -r requirements.txt
```

使うライブラリは次の3つです。

- pywinauto：キー送信
- keyboard：PgDn / PgUp の監視
- pyperclip：日本語の貼り付け

財務エントリを管理者として実行している場合は、このスクリプトも管理者として起動したコマンドプロンプトから実行してください。そうしないと、Windows の仕組み上キーが届きません。

## 使い方

### 1. 送る予定の操作を確認する（キーは送りません）

```bash
py zaimu_input.py 通帳.csv --month 1 --dry-run
```

### 2. メモ帳で練習する

メモ帳を開いてから実行します。

```bash
py zaimu_input.py 通帳.csv --month 1 --notepad
```

記録は本番とは別のファイルに保存されます。

### 3. 本番

```bash
py zaimu_input.py 通帳.csv --month 1
```

1. 実行すると、CSV のチェック結果が表示されます。「入力を始めますか？」に `y` と答えます。
2. 財務エントリの「会計伝票」画面（月次入力）を開き、入力する月にして、カーソルを新しい行の **税区分** の欄に置きます。
3. **PgUp** を押すと入力が始まります。
4. 途中で止めたいときは **PgDn** を押します。再開は **PgUp** です。終了するときは、コマンドプロンプトの画面をクリックして **Ctrl+C** を押します。

### 月の指定

| 例 | 意味 |
|---|---|
| `--month 1` | CSV のうち、1月の仕訳だけを入力する |
| `--month 2026-01` | 年も指定する（CSV に複数の年の1月がある場合は必要） |

### 途中からの再開

- 1仕訳の入力が終わるたびに、`<CSV名>_<月>.progress.json` に記録します。次に実行すると、続きの行から入力します。
- 1仕訳の途中で終了した場合は、実行時にその旨を表示します。財務エントリに入力途中の行が残っていれば、手で消してから続けてください。
- 最初から入力し直すときは `--reset` を付けます。CSV の行番号（見出しを1行目とする）を指定するときは `--from-line 5` のようにします。
- 入力した仕訳は `zaimu_input.log` にも残ります。

### 入力前のチェック

次のいずれかに当てはまると、キーを1つも送らずに終了します。

- 借方科目が 9411・1113 以外、または貸方科目が 9311・1113 以外のとき
- 摘要が全角15文字（30バイト）を超えるとき
- 日付や金額を読み取れないとき
- 財務エントリで使えない文字（Shift_JIS にない文字）を含むとき

チェックの内容は `config.toml` の `[check]` で変えられます。

### ウィンドウの調べ方

```bash
py zaimu_input.py --watch-window
```

最前面のウィンドウのタイトル、プロセスID、プログラム名を表示し続けます。一覧ウィンドウのタイトルを調べるときに使います。

## CSV の形式

1行目は見出しです。文字コードは UTF-8 と Shift_JIS のどちらでも読めます。列の順番は問いません。見出しの名前で読み取ります。

```
日付,伝票番号,借方科目コード,借方科目名,借方補助コード,借方補助名,借方部門コード,貸方科目コード,貸方科目名,貸方補助コード,貸方補助名,貸方部門コード,金額,消費税区分,消費税額,取引先名,摘要,伝票メモ
```

実際に使う列は、日付・借方科目コード・貸方科目コード・金額・取引先名・摘要の6つです。サンプルは `sample/sample.csv` にあります。
