# 財務エントリ 自動入力（会計伝票・月次入力）

通帳の CSV に入っている仕訳を、TKC「財務エントリ」の会計伝票画面へ、そのまま自動で入力します。
CSV を選び、ボタンを押すだけで使えます。関与先の登録などは必要ありません。

## 最初の準備（1回だけ）

1. ブラウザで https://github.com/kei-hub1/kaikei-soft/tree/claude/sleepy-heisenberg-zcx9hn を開きます。緑色の「**Code**」ボタンを押し、「**Download ZIP**」を押します。
2. ダウンロードした ZIP ファイルを右クリックし、「**すべて展開**」を押します。展開したフォルダーは、分かりやすい場所に置きます（例：`C:\財務エントリ自動入力`）。
3. フォルダーの中の「**準備.bat**」をダブルクリックします。
   - 必要なライブラリが入り、デスクトップに「**財務エントリ自動入力**」のショートカットができます。
   - 「Windows によって PC が保護されました」と表示されたら、「詳細情報」を押し、「実行」を押します。

## 最新の版にする（更新）

1. 自動入力の画面を閉じます。
2. フォルダーの中の「**更新.bat**」をダブルクリックし、表示に従って進めます。

最新の版を自動でダウンロードして、ファイルを入れ替えます。どこまで入力したかの記録（「記録」フォルダー）はそのまま残ります。

## 使い方

1. デスクトップの「**財務エントリ自動入力**」をダブルクリックします。
2. 「**CSV を選ぶ**」を押し、通帳の CSV を選びます。
   - 通帳の CSV ファイルを、デスクトップの「財務エントリ自動入力」の上にドラッグ＆ドロップしても開けます。
3. 消費税の「**課税**」か「**免税**」を選びます。免税の関与先では、借方科目の欄から入力します。
   - 普通預金に補助科目がある関与先は、「**補助コード**」の欄に、財務エントリで確かめた普通預金（1113）の補助コードを入れます。CSV の普通預金の行すべてに、その補助コードが入ります。補助科目がない関与先は空欄のままにします。
4. 入力する**月**を選びます。月ごとに、件数と「未入力」「入力済み」などの状態が表示されます。
5. 「**確認**」を押し、入力される内容を見ます（キーは送りません）。
6. 財務エントリで、入力先の関与先の「会計伝票」（月次入力）を、その月にして開きます。
7. 「**入力開始**」を押し、表示された内容を確かめて「はい」を押します。
8. 財務エントリの画面をクリックし、カーソルを新しい行の「**税区分**」の欄に置きます（免税のときは「**借方科目**」の欄）。
9. **PgUp** を押すと入力が始まります。

```
CSV    [C:\Users\...\望月_通帳.csv          ] [CSV を選ぶ]
消費税 ○課税（税区分の欄から入力）  ○免税（借方科目の欄から入力）
月     ┌──────────┬────┬──────────┐
       │ 2026年1月 │ 32 │ 入力済み   │
       │ 2026年2月 │ 28 │ 未入力     │
       └──────────┴────┴──────────┘
[確認] [入力開始] [中止]          [この月の記録を消す]
```

| 入力中の操作 | キー・ボタン |
|---|---|
| 一時停止 | **PgDn** |
| 再開 | **PgUp** |
| やめる | 自動入力の画面の「**中止**」ボタン |

- 画面の下の「**速さ**」で入力の速さを選べます（ゆっくり／標準／速い／とても速い／最速）。選んだ速さは次回も使われます。速くしてずれるようなら、1段階遅くしてください。
- 「**続けて次の月も入力する**」にチェックが入っていると、選んだ月から CSV の最後の月まで続けて入力します。月の変わり目では、財務エントリを自動で次の月に切り替えます（F4 → Enter → トップページで「11」→ Enter → 入力済みデータ年月の確認で ↓ → Enter → エントリ基本情報で Enter）。切り替えの操作と待ち時間は `config.toml` の `[[month_switch]]` で変えられます。自動の切り替えは「すぐ次の月」にだけ使います。月が飛ぶとき（例：1月の次が3月）や年をまたぐときは、一時停止するので、手で切り替えて PgUp を押します。切り替えのあと会計伝票が開いたことを確かめられないときも、仕訳を入力せずに止まります。
- 「**1件ごとに止めて確認する**」にチェックを入れると、1件入力するたびに止まります（PgUp で次へ）。
- 「**入力中はこの画面をしまう**」にチェックが入っていると、入力が始まると自動入力の画面がタスクバーにしまわれます。止まったとき・終わったときに自動で出てきます。
- 送ったキーを1つずつ記録する「記録\詳細ログ.txt」は、速さが「ゆっくり」のときだけ残します（記録する分だけ遅くなるため）。
- 財務エントリ以外のウィンドウが前に出ると、自動で一時停止します。
- 途中でやめても、どこまで入力したかを覚えています。同じ CSV で次に「入力開始」を押すと、続きから入力します。
  - 1件の途中でやめた場合は、財務エントリに入力途中の行が残ります。手で消してから続けてください。
  - 入力の途中で CSV の行を足したり消したりしても、入力済みの仕訳は飛ばして、続きから入力します。CSV を別のフォルダーへ移したり、名前を変えたりしても同じです。
  - 入力済みの仕訳そのもの（日付・科目・金額・取引先名・摘要）を CSV で書き換えた場合は、入力せずに知らせます。
- その月を最初から入力し直すときは、「**この月の記録を消す**」を押します。

### CSV に誤りがあるとき

次のいずれかに当てはまる仕訳があると、その月は1件も入力せずに知らせます。

- 課税の関与先で、税区分が空なのに 9411・9311・1113 以外の科目が入っているとき（税区分の入れ忘れ）
- 摘要が全角15文字を超えるとき
- 日付や金額を読み取れないとき
- 同じ科目（例：1113）で、補助コードのある行とない行が混ざっているとき（入れ忘れの可能性があるため）

## CSV の形式

- 1行目は見出しです。文字コードは UTF-8 と Shift_JIS のどちらでも読めます。
- 列は見出しの名前で読み取るため、順番は問いません。
- 実際に使う列は、日付・借方科目コード・貸方科目コード・金額・税区分・事業区分・取引先名・摘要の8つです。
- **科目コード**：CSV に書かれた科目コードを、そのまま入力します（どの科目でも入力できます）。
- **税区分**：課税の関与先では、CSV の税区分の番号をそのまま入力します。空の行は、9411・9311・1113 だけの行に限り「0」として入力します。仕入れの区分（5・51〜53・6・61〜63・7・71〜73・8）の行では、取引先名のあとに開く「仕入日」を Enter で進めます。免税の関与先では税区分は使いません。
- **事業区分**：売上の行だけ番号を入れます。番号が入っている行だけ、「業」の欄で番号を打って Enter を押します。
- **補助コード**：CSV の補助コードの列は空欄で構いません。普通預金の補助コードは、自動入力の画面の「補助コード」の欄で入れます。雑費や租税公課など、普通預金以外の科目に補助科目がある場合は、CSV の補助コードの列（出金なら借方補助コード、入金なら貸方補助コード）に番号を入れます。補助科目のある科目なのに補助コードが空だと、入力がずれます。

```
日付,伝票番号,借方科目コード,借方科目名,借方補助コード,借方補助名,借方部門コード,貸方科目コード,貸方科目名,貸方補助コード,貸方補助名,貸方部門コード,金額,税区分,事業区分,取引先名,摘要,伝票メモ
```

## フォルダーの中身

| ファイル・フォルダー | 内容 |
|---|---|
| `準備.bat` | 最初の1回だけ使う |
| `起動.bat` | デスクトップのショートカットから呼ばれる |
| `更新.bat` | 最新の版にするときに使う |
| `config.toml` | キー操作の順番などの設定 |
| `記録\` | どこまで入力したかと、入力ログ（自動で作られる） |

最新の版にするときは「更新.bat」を使います。「記録」フォルダーはそのまま残ります。

## うまくいかないとき

- **キーが財務エントリに届かない**：財務エントリを管理者として実行している場合、このツールも管理者として実行しないとキーが届きません。
- **画面が開かない**：フォルダーに「エラー.txt」ができていれば、その中身を知らせてください。
- **キー操作の順番を変えたい**：`config.toml` の `[[steps]]` を書き換えます。書き方はファイルの中に説明があります。
