# TKC会計システム コード表

## このファイルについて

- TKC会計システムで使用する「勘定科目コード」と「課税区分コード」の対応表です。
- 「未確定」「未確認」と記載した項目は、資料間で番号が一致していない、または番号を確認できていないものです。確定コードとして扱わないでください。
- 表に記載のないコードは、推測で補わないでください。
